# 
electron-gon is a repackaging of Landgreen's game N-Gon ran inside of a Electron window. As akin to N-Gon's ability to be ran purely off of the source code, electronGon does exactly that.
# how to download and play electron-gon
To play electron-gon, download the latest version (currently only available for x64 Windows machines) [from this Github repository.](https://github.com/enter-field/electron-gon/releases) After doing that, extract the `.zip` file, and open the `electron-gon.exe` executable, and you are off playing.
